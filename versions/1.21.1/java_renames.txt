# The 1.21.1 build's rewriting of the main tree's Java (tools/assemble.py and public/gradle/versions.gradle apply it; the format is
# described in public/gradle/versions.gradle). Each rule gives a name the main tree uses under 26.x the name 1.21.1 has for the same
# class, field or method, or leaves out a call 1.21.1 has no counterpart for (each such rule says why): no rule changes what the code
# does. Where 1.21.1 differs in more than a name, the code goes through compat/Compat.java (1.21.1's own copy is in
# versions/1.21.1/common/src/main/java/.../compat/), or through a thin base class of this build's own (the rules below the line
# "Base classes"). A rule that no longer finds what it looks for leaves a 26.x name in place, which 1.21.1 does not have, so the build
# fails to compile: nothing goes wrong unseen.
#
